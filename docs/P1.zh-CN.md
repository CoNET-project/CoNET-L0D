# P1 — 在现役 L0 原语上的 overlay TCP

**成对：** [English](./P1.md)  
**Revision：** 2026-08-17（里程碑评估 21:50Z）

公开 how-to：[Applications](https://gitbook.conet.network/applications/conet-l0d.html) · [Developers](https://gitbook.conet.network/developers/conet-l0d.html)

Crate MVP（TUN + iptables + 定位符 + 收包计数）**已验收**。本页是下一 crate 阶段。

## 目标

把 overlay IPv4（发往对端 vIP 的 geth / beacon TCP）做成钱包对钱包字节流，**复用现役** Layer Minus 原语。不得把未上线的 SI 命令 `p2p_stream_*` 或 `listenKind: "l1p2p"` 写成现役。

## 线合同（复用，不分叉）

| 对象 | 加密目标 | HTTP |
| --- | --- | --- |
| Overlay 载荷 | 对端 **user PGP** | 健康入口 **A ≠ B** |
| Mailbox 工作包（`NoPush`） | Mailbox **B route PGP** | 仍是 `{ "data" }` — 禁止 HTTP 旁路字段 |
| Listen | **B route PGP**，`command: mining` + `listenKind: "chat"`，且必须用 **专用 routing EOA** | 健康入口 **C ≠ B** |

HTTP JSON 只能是 `{ "data": "<OpenPGP armor>" }`。禁止在 HTTP 对象上放 `NoPush` / `beamioNoPush`。

信封（内层明文，再 OpenPGP）：

```json
{"type":"conet_l0d_overlay_v1","from":"0x…","seq":1,"ipv4":"<raw IPv4 的 standard base64>"}
```

本修订没有 `signMessage`。禁止把明文 JSON 当作 `data` POST。

AddressPGP：[`0x684b0ac760cEE9c9b85de36d69746420648Cf9e2`](https://mainnet.conet.network/address/0x684b0ac760cEE9c9b85de36d69746420648Cf9e2)。RPC：`https://rpc1.conet.network` 或 `https://publicrpc.conet.network`。

## 配置

`[l0]` **默认关闭**。实验室 `.45` / `.98` 可运行具备 P1 能力的二进制，并在现役 mailbox 路径上证明双向 overlay 帧之前保持 **关**。装二进制 ≠ 现役 mailbox 客户端。

```toml
[l0]
enabled = false
rpc = "https://rpc1.conet.network"
address_pgp = "0x684b0ac760cEE9c9b85de36d69746420648Cf9e2"
# entries = ["https://<existing-guardian>.conet.network"]
# routing_eoa = "0x<dedicated-routing-eoa>"
# routing_key_file = "/etc/conet-l0d/routing.key"

# [[peers]] 实验室覆盖（不得打日志）：
# user_pgp_file = "/etc/conet-l0d/peer-user.asc"
# route_pgp_file = "/etc/conet-l0d/peer-route.asc"
```

Routing EOA ≠ Chat 钱包 ≠ deposit keystore ≠ fee recipient。不得把密钥文件打进日志。

出站 **fail-closed**：需要 `[l0].enabled`，以及对端 **user PGP** 文件、对端 **route PGP** 文件、至少一个 entry。禁止只加密给 user PGP 就 POST。`routing_key_file` 是入站解密用的 OpenPGP **私钥**证书，出站不需要。禁止在 B 可解密的 listen 命令里放 `Securitykey`。

## 操作员铁律

在对端 TUN 上证明**双向** overlay 帧之前，**不要**把 geth `--nat=extip` 或 beacon `--p2p-host-ip` 切到 overlay vIP。实验室主机继续通告**公网 IP**。

## 范围外（不算 P1 开局失败）

- 开启 `[l0]` / 向生产 SI POST / 把通告切到 overlay vIP
- 重启或 wipe geth / beacon / validator
- 新 SI 命令或新域名
- UDP discv4 / discv5（那是 P2）
